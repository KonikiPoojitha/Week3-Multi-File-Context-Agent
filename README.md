Week 3 - Multi-File Context Agent

Project Overview

The Multi-File Context Agent is a Python-based project designed to work with multiple files, build context, and execute tasks using modular components.

Features

- Multi-file context building
- AI agent integration
- Calculator functionality
- File editing and execution
- Automated calculator testing

Technologies Used

- Python
- Large Language Models (LLMs)
- Pytest

Project Structure

- "ai_agent.py" - AI agent logic
- "calculator.py" - Calculator operations
- "context_builder.py" - Context creation
- "editor.py" - File editing
- "executor.py" - Task execution
- "llm.py" - Language model integration
- "main.py" - Main application
- "test_calculator.py" - Calculator tests
- "requirements.txt" - Dependencies
- ".env.example" - Environment configuration example
- "logs/" - Log files

Installation

1. Clone this repository.

2. Install dependencies:
   
   "pip install -r requirements.txt"

3. Configure the required environment variables using ".env.example".

Run the Project

Run the main application using:

"python main.py"

Run Tests

Run the calculator tests using:

"pytest test_calculator.py"
